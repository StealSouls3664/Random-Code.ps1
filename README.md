# Random-Code.ps1
Some random PowerShell code that, when run, does some cool tricks.

## Notices
This code does not edit or read any personal files. For best results, create a folder with nothing else but the PowerShell script.

## How to run
1. First, open PowerShell in the folder you downloaded this file to.
2. Then, run [Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned]
3. Finally, run [.\\"Random Code.ps1"]
